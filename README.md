# Brew Heaven image refresh

This is a static Netlify-ready deployment folder. Upload this folder as the site's publish directory, or drag it into Netlify Deploys.

The original layout, content, menu filtering, order interactions, and responsive styling are retained. CSS illustration panels have been replaced with local café photography in AVIF, WebP, and JPEG fallback formats.

Images are served in AVIF first, WebP next, then JPEG for broad browser support. The image panels retain the original responsive dimensions and use `cover` cropping to avoid layout shifts.
