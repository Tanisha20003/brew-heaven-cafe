# Brew Haven V2

A responsive Next.js café website with a redesigned home page, menu filters, order feedback, gallery, reservation form, and contact form.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deploy on Netlify

1. Push these files to a GitHub repository.
2. Create a new Netlify site from that repository.
3. Netlify will read `netlify.toml` and use `npm run build` automatically.

The image content is served from Unsplash at runtime, so no bulky image assets need to be committed.
